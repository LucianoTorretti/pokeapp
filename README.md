# PokeApp

Pokédex web con los 151 Pokémon de la primera generación, construida sobre la [PokéAPI](https://pokeapi.co/). Permite buscar por nombre y filtrar por tipo. Proyecto de práctica de consumo de APIs REST con JavaScript, sin frameworks.

## Qué practiqué

- Peticiones HTTP con `fetch` a una API pública (151 peticiones en paralelo, cada una en su lugar).
- Manejo de respuestas JSON, búsqueda y filtros por tipo en el DOM.
- Maquetación con HTML y CSS.

## Cómo ejecutarlo

Abre `index.html` en el navegador. No necesita instalación.
